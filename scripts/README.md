# About the Scripts
## 1KF-test-0.4.2.user.js
Tampermonkey script for Jstris made by @Justin1L8. Lines 12-33 added by @had0j to activate the script more consistently.

## 1KF.ahk
AutoHotKey v2 script made by @sillyshark321.\
When activated, press `Esc` to stop all. You need to manually change the controls on your Tetris client.
| Key | Control |
| --- | --- |
| `←` | Left       |
| `→` | Right      |
| `↓` | Soft Drop  |
| `↑` | Hard Drop  |
| `-` | CCW        |
| `=` | CW         |
| `[` | 180        |
| `]` | Hold       |

You also have to change the keycodes if you're using a different keyboard layout (default set to QWERTY).
